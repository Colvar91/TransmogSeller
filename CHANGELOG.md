# Changelog

## 1.2.0

- Automatically select UI and chat language from the WoW client locale.
- Add English, German, French, Spanish, Italian, Portuguese, Russian, Korean, Simplified Chinese and Traditional Chinese translations.
- Fall back to English for unknown locales and missing translations.
- Widen settings controls for translated labels; preserve character settings.

## 1.1.0

- Rename RaidQuickSell to TransmogSeller.
- Add a movable settings window opened with `/ts`.
- Add controls for item level, automatic selling, speed, protection, exceptions, preview and stopping.

## 1.0.0

- Initial automatic merchant selling with an inclusive item-level limit.
- Support soulbound and unbound BoE equipment.
- Add protection options, bounded retries and cancellation safeguards.
